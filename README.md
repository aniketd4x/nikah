# Polygamy Matrimony (polygamymatrimony.com)

A modern, elegant, and privacy-focused Muslim matrimonial and Nikah web application frontend prototype.

## 🌟 Overview
Polygamy Matrimony is crafted to provide a dignified, Shariah-compliant matrimonial experience combining the smooth, swipeable interactions of modern mobile apps with the thoroughness and family involvement essential to Islamic matrimony.

## ✨ Key Features
- **Modern Islamic Aesthetics**: Deep emerald green, warm gold accents, soft cream background, and delicate geometric accents.
- **Dual Responsive Layout**: Tailored for both desktop (spacious multi-column dashboard, split messenger, sticky filter sidebars) and mobile devices (native app-feel bottom navigation, full-screen sheets, responsive touch targets).
- **24 Complete Frontend Screens**:
  - Landing / Home
  - Authentication (Login & Register with Groom/Bride toggle)
  - 8-step Onboarding Wizard with Progress Tracker
  - Home Dashboard with Daily Picks & Recommendations
  - Discover Mode (Swipe & Card Discovery)
  - Search & Advanced 15+ Dimension Filters
  - Search Results (Grid / List view with sorting)
  - Full Profile Details (Photo gallery, spiritual outlook, career, family, partner preferences)
  - Interests & Requests (Received, Sent, Accepted, Declined tabs)
  - Matches (Mutual, Highly Compatible, New)
  - Saved Favorites (All, Recent, Online)
  - In-App Messenger with Simulated Replies & Islamic Icebreakers
  - Activity & Notifications Center
  - My Profile Dashboard & Profile Strength Meter
  - Edit Profile Multi-Section Form
  - Trust & 4-Tier Verification Center (with Selfie Liveness simulator)
  - Partner Preferences Matching Setup
  - Privacy & Safety Controls (Photo Blur, Guardian Mode, Blocked list)
  - Subscription Plans (Free, Premium Blessed, Royal Nikah Elite)
  - Nikah Success Stories & Testimonials
  - Islamic Pre-Marital Guidance (Istikhara guide, 50 pre-nikah questions, Wali involvement, Rights & Responsibilities)
  - Account Settings
  - Help Center & Support Form
- **Realistic Demo Data**: 32 diverse, comprehensive Muslim profiles across India (Mumbai, Delhi, Hyderabad, Pune, Bangalore, etc.) and international locations (Dubai, London, Toronto, New York, Doha, Riyadh).
- **Interactive State**: Mutual match celebrations with confetti animations, toast notification stack, photo liveness checks, and real-time filter synchronization.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/aniketd4x/nikah.git

# Navigate to the project directory
cd nikah

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

The app will be available at `http://localhost:3000`.

### Building for Production
```bash
npm run build
```
